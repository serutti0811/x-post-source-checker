X投稿 オーガニック / プロモ判定チェッカー

X の投稿 URL を貼ると、その投稿に「広告マネージャーで作るカード(ウェブサイトカード等)」が付いているかを判定します。
あわせてインプレッション(再生数)・リポスト・いいねも表示します。

・データ取得には外部サービス(FxEmbed / api.fxtwitter.com)を利用しています。X 公式ではないため、まれに応答しないことがあります。取得できるのは X 上で誰でも見られる公開情報のみです。
・「広告マネージャー作成」は投稿の作成経路の判定です。いま実際に広告が配信中かどうかは、投稿主の X Ads Manager でしか確認できません。
・判定方法: 画像・動画があるのに本文に画像リンク(pic.x.com)が付いていない投稿を、カード付きと判定します。2026-11-02 に 68 件で X のカード情報と突き合わせ、全件一致を確認しています。
